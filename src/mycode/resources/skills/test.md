# 运行并分析项目测试

按照以下流程验证项目：

1. 先读取项目配置和现有测试目录，识别实际使用的语言、包管理器和测试框架。
2. 选择项目已经配置的测试命令，例如 `go test`、`pytest` 或 `npm test`，不要凭习惯引入新的测试工具。
3. 运行测试并保留失败命令、退出码和关键输出。
4. 结合相关实现和测试代码判断失败属于哪一类：
   - 生产代码行为错误，导致原本合理的测试失败；
   - 测试自身的断言、fixture 或环境假设错误。
5. 报告判断依据和建议处理方向，但不要修改任何文件。
6. 全部通过时说明实际运行了哪些测试，并指出明显未覆盖的边界或错误路径；不要把“看起来没问题”当成测试证据。
