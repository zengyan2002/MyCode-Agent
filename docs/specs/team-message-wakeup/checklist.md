### 观察到的行为

- 首轮尚未结束时，后续消息已成功落盘，运行并发数始终为 1；放行后连续两条消息分别进入后续轮次。
- 成员已经等待时，连续两次邮箱检查均读到 wake=false 消息，但模型调用数不增加；收到 wake=true 后一起处理。
- 已读批次确认后，新消息仍未读；包含中文及 emoji 的消息按实际字节位置确认。
- 空闲检查期间反复使用同一个尚未完成的后端等待任务；取消 Host 后测试中的等待任务回收，Runtime 关闭。
- Supervisor 对 RUNNING 成员仍不发送终端输入，持久化唤醒消息保证后续处理；已结束成员没有重启。
- 新增的空闲握手测试证明，Host 已初始化并进入 IDLE 时，Supervisor 可以正常完成握手。
